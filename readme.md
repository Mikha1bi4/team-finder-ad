# TeamFinder

[![Python Version](https://img.shields.io/badge/python-3.10%2B-blue)](https://python.org)
[![Django Version](https://img.shields.io/badge/django-5.2%2B-green)](https://djangoproject.com)
[![Docker](https://img.shields.io/badge/docker-ready-blue)](https://docker.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

TeamFinder — это платформа для поиска единомышленников и совместной работы над pet-проектами. Разработчики, дизайнеры и другие специалисты могут публиковать идеи проектов, находить команду и откликаться на предложения.

---

## Функциональность

### Пользователи и аутентификация
- Регистрация и вход по email и паролю.
- Смена пароля для авторизованных пользователей.
- Публичные профили с аватаром, контактами (email, телефон, GitHub), описанием и списком проектов.
- Редактирование профиля (общая информация, аватар, контакты).
- Управление навыками (скилами) через поле с автодополнением (добавление/удаление без перезагрузки страницы).

### Проекты
- Создание, редактирование и завершение проектов.
- Публикация проекта с указанием названия, описания и статуса (открытый/закрытый).
- Страница проекта с полной информацией, списком участников и кнопкой "Присоединиться".
- Для владельца проекта доступны кнопки "Редактировать" и "Завершить проект".
- Управление необходимыми навыками для проекта через поле с автодополнением (добавление/удаление без перезагрузки).

### Избранное
- Авторизованные пользователи могут добавлять проекты в избранное с главной страницы и со страницы проекта.
- Список избранных проектов доступен только владельцу.
- Удаление проектов из избранного.

### Фильтрация
- Фильтрация пользователей на странице "Пользователи" по четырём критериям:
  - Авторы избранных проектов.
  - Авторы проектов, в которых пользователь участвует.
  - Пользователи, которым нравятся проекты пользователя.
  - Участники проектов пользователя.
- Фильтрация пользователей по навыкам.
- Фильтрация проектов по необходимым навыкам.

### Общие возможности
- Пагинация: по 12 проектов и пользователей на страницу.
- Копирование ссылок на профиль и проект в буфер обмена.
- Отклик на проект (присоединение к команде).

### Административная панель
- Полный контроль над пользователями и проектами.
- Создание, блокировка и удаление аккаунтов.
- Редактирование и удаление любых проектов.
- Смена пароля любого пользователя.

## Стек технологий

- Backend: Django 5.2.4, Python 3.10
- База данных: PostgreSQL
- Frontend: HTML, CSS, JavaScript
- Контейнеризация: Docker, Docker Compose

## Требования

Для запуска проекта необходим только Docker и Docker Compose:

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows/Mac)
- Или Docker Engine + Docker Compose (Linux)

## Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/Mikha1bi4/team-finder-ad.git
cd team-finder-ad
```

### 2. Настройте переменные окружения

```bash
cp .env.example .env
```
При необходимости отредактируйте .env.

## Переменные окружения (.env)

| Переменная | Описание | Пример |
| :--- | :--- | :--- |
| `SECRET_KEY` | Секретный ключ Django | `django-insecure-...` |
| `DEBUG` | Режим отладки | `False` |
| `DB_NAME` | Имя базы данных | `postgres` |
| `DB_USER` | Пользователь БД | `postgres` |
| `DB_PASSWORD` | Пароль БД | `postgres` |
| `DB_HOST` | Хост БД | `db` |
| `DB_PORT` | Порт БД | `5432` |

### 3. Запустите проект
```bash
docker-compose up --build
```

### 4. Выполните миграции и создайте суперпользователя
```bash
docker-compose exec django_app python manage.py migrate
docker-compose exec django_app python manage.py createsuperuser
```

### 5. Остановка проекта

```bash
docker-compose down
```
